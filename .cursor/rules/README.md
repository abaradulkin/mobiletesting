# Правила Cursor для проекта Mobile Testing

Этот каталог содержит правила для AI-ассистента Cursor, которые автоматически применяются при работе с кодом.

## Доступные правила

### test_creation.mdc

**Применяется к:** Файлам тестов (`test_*.py`, `*_test.py`) и директории `tests/`

**Основные принципы:**

#### 🚀 Стратегия запуска тестов

| Что изменил | Что запускать | Время |
|-------------|---------------|-------|
| 1 конкретный тест | Только этот тест | ~10-20 сек |
| Параметризованный тест | Весь параметризованный тест | ~30-60 сек |
| Тестовый класс | Весь класс | ~2-5 мин |
| Фикстуру (`conftest.py`) | Smoke тесты | ~25 сек |
| Page Object | Smoke тесты | ~25 сек |
| Utils/Config | Smoke тесты | ~25 сек |

#### ⚡ Золотое правило

> **НЕ запускать smoke и измененные тесты одновременно!**
> 
> Выбирай ОДНУ стратегию:
> - **Локальные изменения** → измененные тесты
> - **Глобальные изменения** → smoke тесты

#### 📝 Комментирование

**✅ Комментировать:**
- Неочевидную логику
- Workarounds и хаки  
- Технические ограничения

**❌ НЕ комментировать:**
- Очевидные операции
- Параметризованные аргументы (если самоочевидны)
- Стандартные действия

---

## Примеры команд

```bash
# Изменил один тест
pytest tests/test_addition.py::TestAdditionBasic::test_addition_2_plus_2 -v

# Изменил фикстуру или Page Object
pytest -m smoke -v

# Изменил весь класс
pytest tests/test_addition.py::TestAdditionBasic -v
```

## Как работают правила

Cursor автоматически применяет правила из файлов `.mdc` в этой директории при работе с соответствующими типами файлов.

**Полная документация:** см. `test_creation.mdc`
